**Theme**: Families, random effects, and model building

## Goals

Create the model specification interface. Port ratiod's family system and adapt for compositional likelihoods. Implement the full random effects specification system including correlated slopes, nested, and crossed structures.

## Ports from ratiod

### Family Framework (`R/family.R`)

Adapt ratiod's family pattern for compositional distributions:

```r
# ratiod family pattern:
ratiod_negbin_negbin <- function(link_num = "log", link_den = "log", ...) {
  structure(list(
    family = "negbin_negbin",
    link_num = link_num,
    link_den = link_den,
    ...
  ), class = "ratiod_family")
}

# SIMP adaptation:
simp_dirichlet <- function(link = "log") {
  structure(list(
    family = "dirichlet",
    link = link,
    n_params = 1,  # concentration
    param_names = "phi",
    ...
  ), class = "simp_family")
}
```

### Random Effects System

Port ratiod's complete RE infrastructure:

#### Random Intercepts
```r
# Formula: (1 | group)
# ratiod implementation in formula.R:
# - Extracts grouping variable
# - Creates indicator matrix Z
# - Estimates sigma_group
```

#### Random Slopes (Uncorrelated)
```r
# Formula: (1 | group) + (0 + x | group)
# or equivalently: (1 + x || group)
#
# ratiod implementation:
# - Separate variance parameters for intercept and slope
# - No correlation estimated
# - Design matrix Z includes x values
```

#### Correlated Random Slopes
```r
# Formula: (1 + x | group)
#
# ratiod implementation in src/hmc_random_effects.h:
# - Cholesky parameterization of covariance matrix
# - L * L' = Sigma where L is lower triangular
# - Efficient sampling via non-centered parameterization
# - Correlation extracted post-hoc
```

#### Nested Random Effects
```r
# Formula: (1 | region/site)
# Expands to: (1 | region) + (1 | region:site)
#
# ratiod implementation:
# - Automatic expansion in parse_formula()
# - Creates interaction factor region:site
# - Separate variance components
```

#### Crossed Random Effects
```r
# Formula: (1 | site) + (1 | year)
#
# ratiod implementation:
# - Independent random effects
# - Additive contribution to linear predictor
# - Each with own variance parameter
```

### Latent Factors (`R/latent.R`)

Port for unmeasured confounder handling:

```r
# ratiod latent factor specification:
latent_factor(n = 1, prior = prior_pc(u = 1, alpha = 0.01))

# Usage in model:
simp(cover ~ temp + latent_factor(n = 2) + (1 | site), ...)

# Implementation from ratiod:
# - Observation-level random effects
# - PC prior on factor loadings
# - Sum-to-zero constraint for identifiability
# - src/hmc_latent.h for HMC integration
```

### Family Functions

#### `simp_dirichlet(link = "log")`

```r
simp_dirichlet(
  link = "log",           # link for concentration parameter
  concentration = NULL    # fixed value or NULL to estimate
)
```

Likelihood:
```
Y[i] ~ Dirichlet(alpha[i])
alpha[i] = softmax(X[i] * beta) * phi
```

#### `simp_logistic_normal(link = "identity")`

```r
simp_logistic_normal(
  link = "identity",
  reference = "last"      # reference component for ALR
)
```

Likelihood:
```
Y[i] = softmax(eta[i])
eta[i] ~ MVN(X[i] * beta, Sigma)
```

#### `simp_hurdle_dirichlet()`

For structural zeros (adapted from ratiod's hurdle pattern):

```r
simp_hurdle_dirichlet(
  zero_formula = ~ 1,     # predictors for zero probability
  link_zero = "logit",
  link_positive = "log"
)
```

Two-part model:
```
P(Y[i,k] = 0) = logit^-1(X_zero * gamma[k])
Y[i] | Y[i] > 0 ~ Dirichlet(alpha[i])
```

#### `simp_stick_breaking()`

```r
simp_stick_breaking(
  order = NULL            # NULL = estimate, or fixed vector
)
```

### Random Effects Specification

Full lme4-style syntax:

```r
# All supported structures
cover ~ x + (1 | g)                    # random intercept
cover ~ x + (0 + x | g)                # random slope only
cover ~ x + (1 + x | g)                # correlated intercept + slope
cover ~ x + (1 + x || g)               # uncorrelated intercept + slope
cover ~ x + (1 | g1/g2)                # nested
cover ~ x + (1 | g1) + (1 | g2)        # crossed
cover ~ x + (1 + x | g1) + (1 | g2)    # mixed
```

### Component-Specific Effects

New syntax for compositional models:

```r
# All components share coefficient
cover ~ shared(temp)

# Each component has own coefficient
cover ~ varying(precip)

# Mixed (default: fixed effects vary, RE shared)
cover ~ temp + precip + (1 | site)
# Equivalent to:
cover ~ varying(temp) + varying(precip) + (1 | site)
```

### Prior Specification

```r
simp_priors(
  # Fixed effects
  beta = prior_normal(0, 2.5),

  # Random effect SDs
  sigma = prior_half_cauchy(0, 2),

  # RE correlations (if correlated slopes)
  cor = prior_lkj(2),

  # Dirichlet concentration
  phi = prior_gamma(2, 0.1),

  # Component-specific
  beta_temp = prior_normal(0, 1)
)
```
