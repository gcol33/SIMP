### Random Effects Support

All structures ported from ratiod:

```r
(1 | group)              # Random intercepts
(0 + x | group)          # Random slopes only
(1 + x | group)          # Correlated intercept + slope
(1 + x || group)         # Uncorrelated intercept + slope
(1 | g1/g2)              # Nested
(1 | g1) + (1 | g2)      # Crossed
```

## Release Process

### Pre-Release

1. Local checks: `devtools::check()`
2. Multi-platform CI
3. Manual testing on clean system
4. All vignette code runs

### GitHub Release

1. Tag: `git tag -a v1.0.0 -m "SIMP 1.0.0"`
2. Push: `git push origin v1.0.0`
3. Create GitHub release with notes

### CRAN (Optional)

1. Update cran-comments.md
2. `devtools::submit_cran()`
3. Address feedback

## Post-Release

### Maintenance

```
main           # Development (1.1.0)
release-1.0    # Bug fixes (1.0.x)
```

### Bug Fix Process

1. Fix on main
2. Cherry-pick to release-1.0
