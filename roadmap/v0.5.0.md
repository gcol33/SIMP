# SIMP v0.5.0 - Diagnostics & Visualization

**Theme**: Convergence checks, model comparison, and visualization

**ratiod ports**: `R/plot_diagnostics.R`, `R/plot_map.R`, diagnostic functions

## Goals

Port ratiod's comprehensive diagnostic and visualization suite. Provide publication-ready plots for compositional model results.

---

## Ports from ratiod

### Diagnostic Suite (`R/plot_diagnostics.R`)

Direct port of ratiod's diagnostic functions:

```r
# Functions to port directly:
plot_diagnostics(fit)     # Comprehensive diagnostic panel
plot_rhat(fit)            # Rhat convergence
plot_ess(fit)             # Effective sample size
plot_energy(fit)          # HMC energy diagnostic
plot_divergences(fit)     # Divergent transitions
plot_pairs(fit)           # Posterior pairs
plot_acf(fit)             # Autocorrelation

# Diagnostic summaries:
mcmc_diagnostics(fit)     # Table of diagnostics
diagnostic_summary(fit)   # Quick summary
check_diagnostics(fit)    # Pass/fail checks
n_divergent(fit)          # Count divergences
```

### Model Comparison

Port from ratiod with LOO package integration:

```r
# Model comparison functions:
loo(fit)                  # Leave-one-out CV
waic(fit)                 # WAIC
loo_compare(fit1, fit2)   # Compare models
```

### Posterior Predictive Checks

#### `pp_check(fit, type = "dens_overlay", ...)`

```r
# Density overlay
pp_check(fit, type = "dens_overlay")

# By component
pp_check(fit, type = "dens_overlay", component = "sp1")

# Scatter (observed vs predicted)
pp_check(fit, type = "scatter")

# Summary statistics
pp_check(fit, type = "stat", stat = "mean")
pp_check(fit, type = "stat", stat = "prop_zero")
```

#### `residual_plot(fit, type = "fitted")`

```r
residual_plot(fit, type = "fitted")     # vs fitted
residual_plot(fit, type = "predictor", x = "temp")  # vs predictor
residual_plot(fit, type = "qq")         # QQ plot
```

### Model Comparison

#### `loo(fit)` / `waic(fit)`

```r
loo_result <- loo(fit)
print(loo_result)
#> Computed from 4000 posterior draws
#>
#>          Estimate    SE
#> elpd_loo   -234.5  12.3
#> p_loo        15.2   2.1
#> looic       469.0  24.6
#>
#> Pareto k diagnostics:
#>   All k < 0.7: OK
```

#### `loo_compare(fit1, fit2, ...)`

```r
comp <- loo_compare(fit1, fit2, fit3)
print(comp)
#> Model Comparison (ELPD difference)
#> ----------------------------------
#>        elpd_diff  se_diff
#> fit2      0.0       0.0
#> fit1    -12.3       4.5
#> fit3    -28.7       6.2
```

```r
weights <- model_weights(fit1, fit2, method = "stacking")

```

### Compositional Visualization

#### `plot.simp_fit(fit, type = "coef", ...)`

```r
plot(fit, type = "coef")          # Coefficient plot
plot(fit, type = "effects")       # Effects by component
plot(fit, type = "ranef")         # Random effects
plot(fit, type = "caterpillar")   # Caterpillar plot
```

#### `composition_plot(fit, ...)`

```r
# Stacked bar
composition_plot(fit, type = "stacked")

# Ternary (3 components)
composition_plot(fit, type = "ternary",
  components = c("sp1", "sp2", "other"))

# Parallel coordinates
composition_plot(fit, type = "parallel")
```

#### `effect_plot(fit, effects, ...)`

```r
# Marginal effect of predictor
effect_plot(fit, effects = "temp")

# With uncertainty ribbon
effect_plot(fit, effects = "temp", ribbon = TRUE)

# Conditional on other variables
effect_plot(fit, effects = "temp",
  conditions = list(precip = c(500, 1000, 1500)))
```

#### `diversity_plot(fit, index = "shannon", ...)`

```r
diversity_plot(fit, index = "shannon", x = "temp")
```
