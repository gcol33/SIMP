# SIMP v0.1.0 - Foundation

**Theme**: Data structures, validation, priors, and formula parsing

**ratiod ports**: `R/priors.R`, `R/formula.R`, `R/validate.R`

## Goals

Establish the core data infrastructure and port foundational components from ratiod. Create S3 classes for compositional data and adapt ratiod's prior specification and formula parsing systems.

---

## Ports from ratiod

### Prior Framework (`R/priors.R` → `R/priors.R`)

Port ratiod's prior specification system directly:

```r
# ratiod prior functions to port
prior_normal(mean = 0, sd = 1)
prior_half_normal(sd = 1)
prior_half_cauchy(location = 0, scale = 1)
prior_gamma(shape = 1, rate = 1)
prior_exponential(rate = 1)
prior_beta(alpha = 1, beta = 1)
prior_pc(u, alpha)                    # Penalized complexity prior

# Container for model priors
simp_priors(
  beta = prior_normal(0, 2.5),        # Fixed effects
  sigma = prior_half_cauchy(0, 2),    # RE standard deviations
  phi = prior_gamma(2, 0.1),          # Dirichlet concentration
  ...
)
```

**Source files from ratiod**:
- `ratiod/R/priors.R` (lines 1-400)
- Adapt `priors_default()` for SIMP families

### Formula Parsing (`R/formula.R` → `R/formula.R`)

Port ratiod's formula parsing with extensions for multi-component responses:

```r
# ratiod formula parsing handles:
# - Fixed effects extraction
# - Random effects parsing (intercepts, slopes, nested, crossed)
# - Offset terms
# - Process-specific predictors (numerator vs denominator)

# SIMP extension: multi-component response
cbind(sp1, sp2, sp3, other) ~ temp + precip + (1 | site)

# SIMP extension: component-specific effects
cover ~ shared(temp) + varying(precip) + (1 | site)
```

**Source files from ratiod**:
- `ratiod/R/formula.R` (lines 1-300)
- Key functions: `parse_formula()`, `extract_random_effects()`, `validate_formula()`

### Validation (`R/validate.R` → `R/validate.R`)

Port ratiod's input validation patterns:

```r
# ratiod validation style
validate_positive(x, name)
validate_probability(x, name)
validate_integer(x, name)
validate_formula(formula, data)
validate_random_effects(re_terms, data)
```

## New S3 Classes

### `simp_composition`

Core class representing a valid composition (rows sum to 1, all values in [0,1]).

```r
# Constructor
simp_composition(x, species = NULL, validate = TRUE)

# Methods
print.simp_composition()
summary.simp_composition()
as.data.frame.simp_composition()
as.matrix.simp_composition()
`[.simp_composition`()
rbind.simp_composition()
```

**Attributes**:
- `species`: character vector of component names
- `n_species`: integer count
- `n_obs`: number of observations (rows)
- `has_zeros`: logical, whether structural zeros present
- `zero_pattern`: matrix indicating which zeros are structural vs sampling

### `simp_cover`

Subclass of `simp_composition` for vegetation cover data.

```r
# Constructor
simp_cover(x, species = NULL, layers = NULL, residual = "other")

# Additional methods
collapse_layers()
split_layers()
```

### Normalization

```r
normalize_cover(x, method = "proportional")
# Methods: "proportional", "residual", "truncate"

add_residual(x, name = "other")

collapse_components(x, mapping)
# Aggregate components according to named list

collapse_layers(x, fun = sum)
# Aggregate vertical strata
```

### Zero Handling

```r

# Classify zeros as structural vs sampling
```
