# SIMP v0.7.0 - Performance

**Theme**: Threading, Laplace approximation, and computational efficiency

**ratiod ports**: `R/backend_laplace.R`, `src/laplace_core.cpp`, threading infrastructure

## Goals

Optimize SIMP for production use. Port ratiod's Laplace approximation for fast approximate inference and enable within-chain parallelization.

---

## Ports from ratiod

### Laplace Approximation (`R/backend_laplace.R`, `src/laplace_core.cpp`)

Fast deterministic inference for model exploration or large datasets:

```r
# ratiod implementation:
# - Newton-Raphson optimization for posterior mode
# - Hessian computation for uncertainty
# - ~100x faster than full MCMC

# SIMP adaptation:
fit <- fit(model, algorithm = "laplace")
#> Using Laplace approximation
#> Converged in 23 iterations
#>
#> Note: Approximation may underestimate uncertainty
```

**Source files**:
- `ratiod/R/backend_laplace.R` (~150 lines)
- `ratiod/src/laplace_core.cpp` (~400 lines)

### Threading Infrastructure

Port ratiod's threading support:

```cpp
// ratiod uses OpenMP for parallel likelihood computation
// src/hmc_core.cpp contains thread-safe accumulation

#pragma omp parallel for reduction(+:log_lik)
for (int i = 0; i < n; i++) {
  log_lik += log_likelihood_i(params, data[i]);
}
```

## New Features

### Algorithm Selection

```r
fit(model,
  algorithm = "nuts",      # default: full MCMC
  # or
  algorithm = "laplace",   # fast approximation
  # or
  algorithm = "pathfinder" # variational (future)
)
```

### Parallel Likelihood Computation

```r
fit(model,
  chains = 4,
  cores = 4,              # parallel chains
  threads_per_chain = 2   # within-chain parallelism
)
```

For large N, parallel likelihood evaluation:

```r
# Automatic for N > 1000
fit(model)
#> Using 4 threads for likelihood computation
```

### Memory Optimization

#### Thinning

```r
fit(model, iter = 8000, thin = 4)  # keep every 4th draw
```

#### Streaming Posterior

For very long chains:

```r
fit(model, iter = 100000,
  streaming = TRUE  # don't store all in memory
)

# Access draws on-demand
draws_subset <- as_draws(fit, iterations = 1:1000)
```

## New Exports

### Algorithm Control

```r
fit(model,
  # Algorithm selection
  algorithm = "nuts",          # "nuts", "laplace"

  # Threading
  cores = 4,                   # parallel chains
  threads_per_chain = 1,       # within-chain parallelism

  # Memory
  thin = 1,
  streaming = FALSE
)
```

## Design Decisions

### Laplace vs MCMC

| Aspect | Laplace | MCMC |
|--------|---------|------|
| Speed | ~100x faster | Baseline |
| Accuracy | Approximate | Exact |
| Uncertainty | May underestimate | Correct |
| Use case | Exploration, large N | Final inference |

### Threading Model

- **Between-chain**: Always safe, `cores` argument
- **Within-chain**: OpenMP, `threads_per_chain` argument
- Automatic detection of available cores
