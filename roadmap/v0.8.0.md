## Ports from ratiod

### Spatial Effects (`R/spatial.R`, `src/hmc_car.h`, `src/hmc_gp.h`)

#### Conditional Autoregressive (CAR/ICAR)

```r
# ratiod specification:
spatial_car(region, W = adjacency_matrix, type = "icar")
spatial_bym2(region, W = adjacency_matrix)  # BYM2 decomposition

# SIMP adaptation:
simp(cover ~ treatment + spatial_car(region, W),
     data = regional_data,
     family = simp_dirichlet())
```

**Source files**:
- `ratiod/R/spatial.R` (~1000 lines)
- `ratiod/src/hmc_car.h` (~300 lines): ICAR precision matrix
- `ratiod/src/hmc_bym2.h` (~200 lines): BYM2 parameterization

#### Gaussian Process

```r
# ratiod specification:
spatial_gp(x, y, cov = "exp_quad")
spatial_gp(x, y, cov = "matern32")

# SIMP:
simp(cover ~ elevation + spatial_gp(x, y),
     data = point_data,
     family = simp_dirichlet())
```

**Source files**:
- `ratiod/src/hmc_gp.h` (~500 lines): GP covariance functions, Cholesky

#### Spatially-Varying Coefficients

```r
# ratiod:
spatial_svc(x, y, terms = ~ elevation)

# SIMP:
simp(cover ~ spatial_svc(x, y, terms = ~ elevation),
     data = spatial_data,
     family = simp_dirichlet())
```

### Temporal Effects (`R/temporal.R`)

#### Random Walk

```r
# ratiod specification:
temporal_rw1(time)   # first-order random walk
temporal_rw2(time)   # second-order (smoother)

# SIMP:
simp(cover ~ treatment + temporal_rw1(year),
     data = panel_data,
     family = simp_dirichlet())
```

**Implementation from ratiod**:
- RW1: Δu_t ~ N(0, σ²)
- RW2: Δ²u_t ~ N(0, σ²)
- Efficient sparse precision matrix

#### Autoregressive

```r
# ratiod:
temporal_ar1(time)

# SIMP:
simp(cover ~ treatment + temporal_ar1(year),
     data = panel_data,
     family = simp_dirichlet())
```

**Implementation**:
- AR(1): u_t = ρ u_{t-1} + ε_t
- Stationary constraint: |ρ| < 1

#### Seasonal/Cyclic

```r
# ratiod:
temporal_rw1(time, cyclic = TRUE, period = 12)

# SIMP:
simp(cover ~ temporal_rw1(month, cyclic = TRUE, period = 12),
     data = monthly_data,
     family = simp_dirichlet())
```

#### Time-Varying Coefficients

```r
# ratiod:
temporal_tvc(time, terms = ~ treatment)

# SIMP:
simp(cover ~ temporal_tvc(year, terms = ~ treatment),
     data = panel_data,
     family = simp_dirichlet())
```

### Spatiotemporal (`R/spatiotemporal.R`)

#### Knorr-Held Interaction Types

```r
# ratiod specification:
spatiotemporal(region, year, W, type = "I")   # Independent
spatiotemporal(region, year, W, type = "II")  # Spatial structure, IID temporal
spatiotemporal(region, year, W, type = "III") # IID spatial, temporal structure
spatiotemporal(region, year, W, type = "IV")  # Full interaction

# SIMP:
simp(cover ~ treatment + spatiotemporal(region, year, W, type = "IV"),
     data = panel_regional_data,
     family = simp_dirichlet())
```

## C++ Implementation

### Spatial C++ Code

```cpp
// src/hmc_car.h (port from ratiod)

class CAREffect {
  // ICAR precision matrix (sparse)
  Eigen::SparseMatrix<double> Q;

  // Scaling factor for interpretable variance
  double scale_factor;

  // Log prior: -0.5 * u' Q u (improper for ICAR)
  double log_prior_icar(const VectorXd& u);

  // Proper CAR with rho parameter
  double log_prior_car(const VectorXd& u, double rho);
};

// src/hmc_bym2.h
class BYM2Effect {
  // Convolution of ICAR and IID
  // u = sqrt(rho) * u_spatial + sqrt(1-rho) * u_iid

  double log_prior(const VectorXd& u_spatial,
                   const VectorXd& u_iid,
                   double rho);
};
```

### Temporal C++ Code

```cpp
// src/hmc_temporal.h (port from ratiod)

class RW1Effect {
  // First-order random walk precision
  // Q[i,i] = 2, Q[i,i+1] = Q[i+1,i] = -1 (interior)

  Eigen::SparseMatrix<double> Q;

  double log_prior_rw1(const VectorXd& u);
};

class AR1Effect {
  double rho;  // autocorrelation, |rho| < 1

  double log_prior_ar1(const VectorXd& u);
  double log_prior_rho(double rho);  // transform to ensure stationarity
};
```

### GP C++ Code

```cpp
// src/hmc_gp.h (port from ratiod)

class GPEffect {
  // Covariance function
  enum CovType { EXP_QUAD, MATERN32, MATERN52 };

  // Compute covariance matrix
  MatrixXd compute_cov(const MatrixXd& coords, double length_scale,
                       double marginal_sd, CovType type);

  // Cholesky for efficient sampling
  LLT<MatrixXd> chol;

  double log_prior_gp(const VectorXd& u);
};
```

## Computational Considerations

| Model Type | Complexity | Practical N limit |
|------------|------------|-------------------|
| CAR/ICAR | O(N) sparse | 10,000+ |
| BYM2 | O(N) sparse | 10,000+ |
| GP (full) | O(N³) | ~500 |
| GP (NNGP) | O(Nm²) | 10,000+ |
| RW1/RW2 | O(T) sparse | 10,000+ |
| AR(1) | O(T) | 10,000+ |
| ST Type IV | O(NT) sparse | 5,000+ |

For large spatial datasets, use NNGP approximation:
```r
spatial_gp(x, y, cov = "exp_quad", approximation = "nngp", n_neighbors = 15)
```
