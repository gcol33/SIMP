# SIMP v0.3.0 - Inference Engine

**Theme**: Native C++ HMC/NUTS backend (NO STAN)

**ratiod ports**: `src/hmc_core.cpp`, `src/hmc_sampler.cpp`, `src/autodiff.h`, likelihood headers

## Goals

Port ratiod's native C++ HMC/NUTS sampler to SIMP. Implement compositional likelihoods (Dirichlet, logistic-normal, hurdle) in the autodiff framework. This version makes SIMP fit models without any external dependencies.

---

## Why Native C++ (Not Stan)

1. **Zero compilation overhead**: No Stan installation, no model compilation wait
2. **Portable**: Works on any system with R and a C++ compiler
3. **Proven**: ratiod v1.2.0 uses this backend in production
4. **Control**: Full access to likelihood implementations
5. **Integration**: Tight R-C++ interface via Rcpp

## New Likelihoods for SIMP

### Dirichlet Likelihood

```cpp
// src/likelihood_dirichlet.h

double log_dirichlet(const VectorXd& y, const VectorXd& alpha) {
  // y: observed composition (sums to 1)
  // alpha: concentration parameters (positive)

  double log_prob = lgamma(alpha.sum());
  for (int k = 0; k < y.size(); k++) {
    log_prob -= lgamma(alpha(k));
    log_prob += (alpha(k) - 1) * log(y(k));
  }
  return log_prob;
}

// With autodiff for gradients
ADVar<double> log_dirichlet_ad(const VectorXd& y, const ADVector& alpha);
```

### Logistic-Normal Likelihood

```cpp
// src/likelihood_logistic_normal.h

double log_logistic_normal(const VectorXd& y, const VectorXd& mu,
                           const MatrixXd& Sigma) {
  // Transform to ALR (additive log-ratio)
  VectorXd alr_y = alr_transform(y);

  // Multivariate normal on ALR
  double log_prob = log_mvn(alr_y, mu, Sigma);

  // Jacobian of softmax transformation
  log_prob += log_jacobian_softmax(y);

  return log_prob;
}
```

// src/likelihood_hurdle.h

double log_hurdle_dirichlet(const VectorXd& y, const VectorXd& alpha,
                            const VectorXd& zero_prob) {
  double log_prob = 0;

  // For each component
  for (int k = 0; k < y.size(); k++) {
    if (y(k) == 0) {
      // Zero part
      log_prob += log(zero_prob(k));
    } else {
      // Positive part
      log_prob += log(1 - zero_prob(k));
      // Contribution to truncated Dirichlet handled separately
    }
  }

  return log_prob;
}
