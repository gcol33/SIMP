## Datasets

### Real Datasets

#### `meadow_cover`

Vegetation cover from permanent grassland plots.

```r
data(meadow_cover)
#> meadow_cover: simp_cover object
#> --------------------------------
#> Observations: 240
#> Components: 15 species + bare_ground
#> Sites: 60, Years: 4
#>
#> Variables: site, year, elevation, slope, aspect, soil_moisture, management
```

**Characteristics**:
- Multi-year temporal structure
- Environmental gradients
- Management treatments
- ~35% zeros

#### `forest_understory`

Multi-layer forest understory composition.

```r
data(forest_understory)
#> forest_understory: simp_cover object
#> ------------------------------------
#> Observations: 180
#> Components: 22 species + litter
#> Layers: 3 (herb, shrub, moss)
#>
#> Variables: plot, layer, canopy_cover, light_availability, soil_ph
```

**Characteristics**:
- Vertical stratification
- Light gradient effects
- High zero frequency in specialists

#### `dune_succession`

Coastal dune vegetation along succession gradient.

```r
data(dune_succession)
#> dune_succession: simp_cover object
#> ----------------------------------
#> Observations: 150
#> Components: 18 species + bare_sand
#>
#> Variables: transect, distance_from_sea, dune_age, organic_matter
```

**Characteristics**:
- Strong compositional gradient
- Species replacement patterns
- Bare ground dominant in early succession

```r
data(sim_dirichlet)

```

## Simulation Functions

### `simulate_simp(n, k, ...)`

Generate simulated compositional data:

```r
# Basic Dirichlet
sim <- simulate_simp(n = 100, k = 5, family = "dirichlet", phi = 10)

# With environmental gradient
sim <- simulate_simp(n = 100, k = 5,
  formula = ~ x1 + x2,
  beta = matrix(...),
  family = "dirichlet"
)

# With zeros
sim <- simulate_simp(n = 100, k = 5,
  family = "hurdle_dirichlet",
  zero_prob = c(0, 0, 0.3, 0.5, 0.8)
)

# With random effects
sim <- simulate_simp(n = 100, k = 5,
  formula = ~ x1 + (1 | group),
  groups = rep(1:10, each = 10),
  sigma_group = 0.5
)
```

### `simulate_from_fit(fit, nsim = 1)`

Simulate new data from fitted model:

```r
new_data <- simulate_from_fit(fit, nsim = 10)
```
