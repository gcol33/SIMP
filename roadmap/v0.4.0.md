# SIMP v0.4.0 - Posterior Extraction

**Theme**: Prediction, fitted values, and derived quantities

**ratiod ports**: `R/ratio.R` (contrast logic), `R/methods.R` (fitted, predict)

## Goals

Provide comprehensive tools for extracting and working with posterior quantities. Port ratiod's prediction and contrast framework, adapting for compositional responses.

---

## Ports from ratiod

### Prediction Framework

Adapt ratiod's `predict()` and `fitted()` methods:

```r
# ratiod pattern:
# - predict() generates predictions for new data
# - fitted() returns predictions for observed data
# - Both propagate full uncertainty

# SIMP adaptation:
# - Predictions are compositions (sum to 1)
# - Support component-specific predictions
# - Diversity indices as derived quantities
```

### Contrast Logic (`R/ratio.R`)

Adapt ratiod's `ratio_contrast()` for compositional comparisons:

```r
# ratiod: compare ratios between groups
ratio_contrast(fit, group1, group2)

# SIMP: compare compositions between groups
composition_contrast(fit, group1, group2)
# Returns posterior of difference in each component
```

## New Exports

### Prediction

#### `predict(fit, newdata = NULL, type = "response", ...)`

```r
# Posterior predictive for observed data
pred <- predict(fit)

# Predictions for new data
pred <- predict(fit, newdata = new_sites)

# Different prediction types
predict(fit, type = "response")    # compositions (simplex)
predict(fit, type = "latent")      # latent scale (unconstrained)
predict(fit, type = "linear")      # linear predictor
```

Returns `simp_prediction` object:
```r
print(pred)
#> SIMP Predictions
#> ----------------
#> Type: response
#> Observations: 50
#> Components: 12
#> Posterior draws: 4000
#>
#> Use summary() for point estimates

summary(pred)
#>        sp1_mean sp1_sd sp1_2.5% sp1_97.5% sp2_mean ...
#> obs_1     0.234  0.045    0.152     0.324    0.156 ...
#> obs_2     0.189  0.038    0.118     0.267    0.201 ...
```

#### `posterior_predict(fit, newdata = NULL, ndraws = NULL)`

Raw posterior predictive samples (including observation noise):

```r
pp <- posterior_predict(fit, ndraws = 100)
dim(pp)
#> [1] 100 150  12
#> # draws x observations x components
```

#### `posterior_epred(fit, newdata = NULL, ndraws = NULL)`

Expected value of posterior predictive (no observation noise):

```r
epred <- posterior_epred(fit, ndraws = 100)
```

### Fitted Values

#### `fitted(fit, ...)`

```r
fitted_vals <- fitted(fit)
summary(fitted_vals)
#> Fitted Compositions (posterior mean)
#> ------------------------------------
#>          sp1    sp2    sp3   ... other
#> obs_1  0.234  0.156  0.089  ... 0.312
#> obs_2  0.189  0.201  0.102  ... 0.287
```

#### `residuals(fit, type = "response")`

```r
# Response residuals (observed - fitted)
resid <- residuals(fit, type = "response")

# Aitchison residuals (compositional geometry)
resid <- residuals(fit, type = "aitchison")

# Latent residuals
resid <- residuals(fit, type = "latent")
```

### Parameter Extraction

#### `fixef(fit)` / `ranef(fit)` / `coef(fit)`

```r
fixef(fit)
#> Fixed Effects (posterior summary)
#>              Mean    SD   2.5%   97.5%
#> (Intercept) -0.23  0.15  -0.52    0.06

#>        (Intercept)  temp

coef(fit)
#> Combined Coefficients (fixed + random)
```

### Compositional Contrasts

#### `composition_contrast(fit, ...)`

Compare compositions between conditions (adapted from ratiod's `ratio_contrast()`):

```r
# Compare treatment vs control
contrast <- composition_contrast(fit,
  condition1 = list(treatment = "A"),
  condition2 = list(treatment = "B")
)

print(contrast)
#> Compositional Contrast: A vs B
#> ------------------------------
#> Component   Diff    SD   2.5%  97.5%  P(A > B)
#> sp1        0.045 0.023  0.001  0.089     0.97
#> sp2       -0.023 0.018 -0.058  0.012     0.19
#> sp3        0.012 0.015 -0.017  0.041     0.79
#> ...
```

### Derived Quantities

#### `posterior_diversity(fit, index = "shannon", ...)`

```r
div <- posterior_diversity(fit, index = "shannon")
summary(div)
#> Posterior Diversity (Shannon)
#> -----------------------------
#>        Mean    SD   2.5%   97.5%
#> obs_1  1.82  0.12   1.58    2.05
#> obs_2  1.67  0.14   1.41    1.94
```

Supported indices:
- `"shannon"`: Shannon entropy: -Σ p_k log(p_k)
- `"simpson"`: Simpson's index: 1 - Σ p_k²
- `"invsimpson"`: Inverse Simpson: 1 / Σ p_k²
- `"richness"`: Effective number: exp(Shannon)
- `"evenness"`: Pielou's J: Shannon / log(K)

#### `posterior_dominance(fit, k = 1)`

```r
dom <- posterior_dominance(fit, k = 1)
# Posterior of most abundant component
```

### Probability Queries

#### `prob(fit, expr)`

```r
# Probability that sp1 > sp2
prob(fit, sp1 > sp2)
#>        P(sp1 > sp2)
#> obs_1        0.823
#> obs_2        0.234

# Probability of dominance
prob(fit, sp1 > 0.5)

# Complex conditions
prob(fit, sp1 + sp2 > 0.7)
```

#### `hypothesis(fit, hypothesis, ...)`

```r
hypothesis(fit, "temp > 0")
#> Hypothesis Test
#> ---------------
#> H: temp > 0
#>
#> Estimate  Error  2.5%  97.5%   P(H)
#>    0.412  0.081  0.25   0.57  0.996
```

### Uncertainty Propagation

#### `transform_posterior(fit, fun, ...)`

```r
# Custom transformation with uncertainty
custom <- transform_posterior(fit, function(p) {
  # p is a composition vector
  p[1] / (p[1] + p[2])  # ratio of first two
})
```
