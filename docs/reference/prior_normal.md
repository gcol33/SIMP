# Create a normal prior

Create a normal prior

## Usage

``` r
prior_normal(mean = 0, sd = 1)
```

## Arguments

- mean:

  Prior mean (default 0)

- sd:

  Prior standard deviation (default 1)

## Value

A `simp_prior` object

## Examples

``` r
prior_normal(0, 2.5)
prior_normal(mean = 0, sd = 10)
```
