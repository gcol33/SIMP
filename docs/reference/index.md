# Package index

## Integrate

Advance a Hamiltonian trajectory.

- [`simp_integrate()`](https://gcol33.github.io/SIMP/reference/simp_integrate.md)
  : Integrate a Hamiltonian trajectory
- [`simp_integrate_nonsep()`](https://gcol33.github.io/SIMP/reference/simp_integrate_nonsep.md)
  : Integrate a non-separable Hamiltonian (generalized leapfrog)
- [`simp_integrate_mts()`](https://gcol33.github.io/SIMP/reference/simp_integrate_mts.md)
  : Integrate a split-potential Hamiltonian (multiple time-stepping)

## Sample

Hamiltonian Monte Carlo built on the integrators.

- [`simp_hmc()`](https://gcol33.github.io/SIMP/reference/simp_hmc.md) :
  Hamiltonian Monte Carlo with a chosen symplectic integrator

## Schemes

The available integrators.

- [`simp_schemes()`](https://gcol33.github.io/SIMP/reference/simp_schemes.md)
  : Available symplectic integrators
- [`simp_b_optimal()`](https://gcol33.github.io/SIMP/reference/simp_b_optimal.md)
  : Minimum-error multistage coefficients for a step band
